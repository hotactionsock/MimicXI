Map calibration

Line zone map images (in the site's maps/ folder) up with game coordinates, for the live view. Click three or more spots on the map spread far apart, and give each its in-game position: type it (!where in game) or pick a spawn point. Every spawn point is then drawn on the map, so you can see when it lines up.

Click the map to add a point. The selected point is ringed; pick a spawn point on the right or type coordinates to place it in the world.
